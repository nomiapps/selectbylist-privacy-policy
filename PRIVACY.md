# Privacy Policy — nomiapps

**Last updated: June 2026**

## Overview

Select By List is a Fusion 360 add-in developed and published by nomiapps. This privacy policy describes how the add-in handles data.

## Data Collection

Select By List does not collect, transmit, store, or share any personal data or usage data of any kind.

The add-in runs entirely on your local machine. It reads component, body, and face information from the currently active Fusion 360 design solely to populate the panel UI. This data never leaves your machine and is never written to disk by the add-in.

## Internet Access

Select By List does not make any network requests. No internet connection is required or used at any time.

## Third Parties

Select By List does not integrate with any third-party services, analytics platforms, advertising networks, or cloud services.

## Data Retention

No data is retained. The add-in holds design information in memory only for as long as the panel is open. No data is written to disk and nothing persists between sessions.

## Changes to This Policy

If this policy changes in a future version of the add-in, the updated policy will be published at this URL and the "Last updated" date above will be revised.

## Contact

For questions about this privacy policy, contact: nomiapps via the Autodesk App Store listing page.
